---
title: "Authenticate Proyecto Sheets with Google Sheets API"
sidebarTitle: "Credentials"
description: "Create a Google Cloud service account, download its JSON key, and grant it access to your IMDEL spreadsheet so Proyecto Sheets can connect."
---

Proyecto Sheets authenticates with the Google Sheets API using a **Google Cloud service account** — not a personal OAuth flow. gspread loads the service account's JSON key file at startup and exchanges it for a short-lived access token automatically. This setup is done once; after that the application connects without any user interaction.

<Steps>

  <Step title="Enable the Google Sheets API">
    1. Open the [Google Cloud Console](https://console.cloud.google.com/) and select (or create) your project.
    2. Navigate to **APIs & Services → Library**.
    3. Search for **Google Sheets API** and click **Enable**.
    4. Repeat for **Google Drive API** — gspread requires Drive API access to open spreadsheets by name.
  </Step>

  <Step title="Create a service account">
    1. Go to **IAM & Admin → Service Accounts**.
    2. Click **Create Service Account**.
    3. Give it a descriptive name such as `imdel-sheets-reader`. The service account ID is generated automatically.
    4. Skip the optional role and user-access steps — no project-level IAM roles are required. Click **Done**.
  </Step>

  <Step title="Download the JSON key">
    1. In the Service Accounts list, click the account you just created.
    2. Open the **Keys** tab.
    3. Click **Add Key → Create new key**, select **JSON**, and click **Create**.
    4. The browser downloads a JSON file immediately. Keep it somewhere safe — Google will not give you a second copy of the private key.
  </Step>

  <Step title="Rename and place the file">
    Rename the downloaded file to match the `CREDENTIALS_FILE` constant defined at the top of `interfaz_prueba.py`:

    ```python
    # interfaz_prueba.py
    CREDENTIALS_FILE = "proyecto-sheets-505320-bb8ae069f096.json"
    ```

    The default expected name is `proyecto-sheets-505320-bb8ae069f096.json`. Place the file in the **project root directory** — the same folder that contains `main.py` and `interfaz_prueba.py`.

    ```
    proyecto_sheets/
    ├── main.py
    ├── interfaz_prueba.py
    └── proyecto-sheets-505320-bb8ae069f096.json   ← here
    ```
  </Step>

  <Step title="Share the spreadsheet with the service account">
    1. Open the target Google Sheet (`Tablas IMDEL Prototipo`) in your browser.
    2. Click **Share**.
    3. Paste the service account's email address. You can find it inside the JSON file under the `client_email` field — it looks like `imdel-sheets-reader@your-project-id.iam.gserviceaccount.com`.
    4. Set the access level to **Viewer** (read-only searches) or **Editor** if the application needs to write back to the sheet.
    5. Uncheck "Notify people" (service accounts don't have inboxes) and click **Share**.
  </Step>

</Steps>

<Warning>
  The JSON credentials file contains your service account's private key. It is already listed in `.gitignore`:

  ```
  # .gitignore
  proyecto-sheets-505320-bb8ae069f096.json
  ```

  **Never commit this file to version control.** Anyone who obtains it can access every spreadsheet shared with the service account. Store it outside your repository or in a secrets manager if you deploy to a server.
</Warning>

## Credential file structure

When gspread calls `gspread.service_account(filename=CREDENTIALS_FILE)` it reads the following fields from the JSON key file. The structure looks like this:

```json
{
  "type": "service_account",
  "project_id": "your-project-id",
  "private_key_id": "bb8ae069f096...",        // sensitive – do not share
  "private_key": "-----BEGIN RSA PRIVATE KEY-----\n...",  // sensitive – do not share
  "client_email": "imdel-sheets-reader@your-project-id.iam.gserviceaccount.com",
  "client_id": "123456789012345678901",
  "auth_uri": "https://accounts.google.com/o/oauth2/auth",
  "token_uri": "https://oauth2.googleapis.com/token",
  "auth_provider_x509_cert_url": "https://www.googleapis.com/oauth2/v1/certs",
  "client_x509_cert_url": "https://www.googleapis.com/robot/v1/metadata/x509/..."
}
```

The fields you will reference most often are:

| Field | Purpose |
|---|---|
| `client_email` | Paste this address when sharing the spreadsheet |
| `project_id` | Identifies the Google Cloud project that owns the key |
| `private_key_id` | Short identifier for the key (safe to share for auditing) |
| `private_key` | The RSA private key — **never expose this value** |

<Note>
  The credentials filename is referenced in two places with slightly different patterns. `main.py` hardcodes the path as a string literal in the `gspread.service_account()` call:

  ```python
  # main.py
  gc = gspread.service_account(filename="proyecto-sheets-505320-bb8ae069f096.json")
  ```

  `interfaz_prueba.py` reads it from the `CREDENTIALS_FILE` module-level constant:

  ```python
  # interfaz_prueba.py
  CREDENTIALS_FILE = "proyecto-sheets-505320-bb8ae069f096.json"
  # ...
  self.gc = gspread.service_account(filename=CREDENTIALS_FILE)
  ```

  If you rename the key file, update **both** locations: the string in `main.py` and the `CREDENTIALS_FILE` constant in `interfaz_prueba.py`.
</Note>
