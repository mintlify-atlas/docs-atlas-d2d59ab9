Proyecto Sheets is a Python desktop application built for IMDEL (Instituto Municipal de Desarrollo Local) that lets operators look up beneficiaries by their DNI across every registered social program in a single query. It connects to a Google Sheets spreadsheet via a service account, loads all worksheet data into memory, and searches across all configured sheets instantly — no backend server required.

## How It Works

<Steps>
  <Step title="Authenticate">
    The app reads a Google Cloud service account JSON file and opens the configured spreadsheet with `gspread`.
  </Step>
  <Step title="Load worksheets">
    All 7 worksheets are fetched at startup and cached in memory so searches are instant.
  </Step>
  <Step title="Enter a DNI">
    Type in any 8-digit DNI number. The app normalises formats automatically and checks every worksheet.
  </Step>
  <Step title="Review results">
    Any matches display the beneficiary's full name, coordination, and program name. Refresh the cache at any time without restarting.
  </Step>
</Steps>
